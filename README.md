# 山与行｜广州出发的四天三晚旅行路线

为 2026 年 10 月 4—7 日、三人同行设计的旅行路线网页。共 12 条路线，包含不租车、到达后租车和广州出发自驾三种出行方式。

## 在线访问

[打开网页](https://silence-world-ak.github.io/guangzhou-travel-atlas/)

## 本地运行

在此目录运行：

```bash
npm ci
npm run dev
```

打开命令行显示的本地网址。推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。也可以运行 `npm run build`，把 `dist` 目录部署到其他静态网站服务。

## 页面内容

- 主题与出行方式筛选、目的地搜索。
- 每条路线的停靠点交互地图、四天行程、景点实拍和编辑评价。
- 交通方式、三晚住宿安排、三人费用拆分及人均估算。
- 图片出处和参考资料均可从路线详情页打开。

地图使用 OpenStreetMap 在线底图，连接线仅表示停靠顺序，不能用于导航。费用是国庆出行的规划区间，未接入实时票价或余位。
